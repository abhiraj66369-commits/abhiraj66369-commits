## [1.0.0] - 2026-09-20

### Added

- Data-driven profile README (`data/profile.json` plus `scripts/update_readme.py`).
- Self-hosted animated hero, divider and footer SVGs with reduced-motion support.
- Workflows: contribution snake, metrics cards, profile update, quality checks.
- Dependabot for GitHub Actions versions.
- Offline validator (`scripts/validate_profile.py`) producing a PASS/FAIL report.
- Certification, coding-profile and open-source frameworks that render real data only.
- `SECURITY.md`, `.gitignore`, MIT `LICENSE`, setup and parity documentation.

### Changed

- Replaced the default GitHub profile template.
